3. Gün – Git ve Proje İskeleti

Amaç
Proje için Git sürüm kontrolünü başlatmak, gereksiz ve büyük dosyaları hariç tutan .gitignore dosyasını hazırlamak ve ilk commit kaydını almak.

Yapılan Çalışmalar
- git init ile yerel Git deposunu başlattım.
- venv/, data/, __pycache__/ ve büyük model dosyalarını hariç tutacak şekilde .gitignore dosyasını düzenledim.
- git status ile izlenen dosyaları kontrol edip ilk proje iskeletini commit ettim.

Kullanılan Teknolojiler
- Git, PowerShell, Visual Studio Code

Elde Edilen Sonuç
- Yerel Git deposu, .gitignore kuralları ve ilk commit başarıyla tamamlandı.

Karşılaşılan Sorunlar ve Çözüm
- Sanal ortam ve veri setinin Git geçmişini şişirmemesi için .gitignore kuralları ilk aşamada tanımlandı.
